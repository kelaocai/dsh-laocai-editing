# 视频号文字安全区与遮罩 QC

**适用范围：视频内字幕与包装。独立封面不套用此框，也不缩图补边；封面按 [封面规范](covers.md) 满版输出。**

## 默认约定（用户于 2026-11-01 明确要求长期沿用）

无需每次索要安全区截图。竖屏 1080×1920 默认采用本次内侧白框的保守内接范围：**x=108–972，y=192–1728**（左右各 10%，上下各 10%）。这是根据用户截图整理的本项目默认工作规范，不是微信官方公布的通用像素标准。其他分辨率按比例换算；用户后续明确指定不同范围时以新要求为准。带购物车、预约直播等 UI 时沿用更严格的平台避让检查，不把此框当作所有 UI 状态的保证。

标题、账号名、角标、说明小字、花字、字幕及其描边/阴影/入场动画都必须完整位于框内，再留至少 16px 内边距。背景、人物和 B-roll 可超出文字安全区；不能为满足文字规则一律缩小整个画面。已有压字无法独立移动时才采用整体内收，并检查主体大小是否合适。

## 分层与间距

- 对白字幕独立一层，按实际字形边界排版；通常落在 y=1640–1705，最长行不超过安全区内宽，过长时自然分句或分行并整体上移。
- 底部“AI + AR / 实拍与创作”等小字独立重绘，建议 y≈1560；与字幕实际字形至少留 60px 垂直净距。不能从压字成片裁一条背景连同小字往上贴：这会把实拍条带一起带出。
- 花字优先利用真正留白，不盖人物脸部、操作控件或已有标题。所有动画帧均受安全区约束；例片 35 秒采用两行花字和时钟图形填补横屏下方留白，不把该造型固化为所有视频模板。
- 字幕留白区必须有完整不透明底板。本次修复为 y=1540–1920 全宽深色底板，层次为“视频 → 不透明底板 → 小字/花字/字幕”。该数值是例片布局；其他片按内容调整，避免截掉主体。
- 遮罩覆盖连续区域，不只盖住旧文字的窄条。检查横竖屏切换、手机录屏与下方实拍组合时，下方实拍是否超出预定窗口。优先约束视频窗口/裁切，再用完整底板兜底。

## 最终 QC 必查（不能仅凭自动参数通过）

1. 对最终导出 MP4 生成带安全框的检查副本，白框仅用于审片，不烧入交付。检查所有文字类型的实际字形、描边与动画极值是否越界；有布局坐标时做边界检查，压字片需看真实帧，缺数据不得声称自动验证通过。
2. 抽检每一种版式、最长字幕、首尾、横竖屏切点前后、花字入退场、每个底部小字位置；连续播放问题区间。特别检查手机输入描述/键盘画面与下方实拍组合（本次 01:09–01:14，01:11 曾漏底）。
3. 放大检查字幕周围和底板边缘：无透底、残留横条、双重旧字、视频伸入、字幕与小字相碰；不能只看低分辨率缩略图或渲染前模板。
4. 检查平台 UI 可能遮挡的区域；无真实平台复测时如实注明，不承诺各设备都不会遮挡。
5. QC 记录至少包含：采用的安全框、检查时间点、几何检查结果或限制、遮罩和净距检查、连续播放范围。任一项未通过先修复并复核再交付；自动编码/响度检查通过不代表视觉 QC 完成。
